# 对比度修复验证（2026-10-19）

本地验证：`pnpm contrast:check`（129 项）、`node --test scripts/check-contrast.test.mjs`（7 项）、`pnpm typecheck`、`pnpm registry:build`、`pnpm build` 均通过。

回归用例确认：文字低于 4.5、交互边框、滑块已选区段或圆钮边框低于 3、registry 与 CSS 不一致、循环 token 引用都会失败。4.478 不会因显示时四舍五入而误判通过。

此前 Google Chrome headless + Playwright 在本地 docs 站验证亮/暗切换、按钮 hover、链接、输入边框、键盘焦点和全部显示的色板标签；无页面异常。此前已查看两套主题的页面与输入焦点截图；本轮未重跑浏览器验证。下表为浏览器实际计算颜色的抽样比值，半透明背景与祖先背景合成后计算。

主按钮 hover 数值采用本轮评审提供的浏览器实测结果；静态脚本使用 sRGB 通道按 95% alpha 合成，与浏览器 CSS `color-mix` 的插值口径可能有差异。
