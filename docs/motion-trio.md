# 三项交互动效预览

本地入口：`?preview=motion-trio`。

- Tabs：点击总览／项目进展／最近活动，以及下方时间范围。试试连续切换和键盘方向键。共享底板或下划线跟随选中项，尺寸和字体变化直接校正位置。
- 指标：点击更新数据，四份明确标注的本地快照循环展示。仅变化的数字滑动；首屏无从零计数。MetricCard 默认仍为静态，传 animated 启用。
- 操作反馈：保存配置模拟 900ms 本地操作；勾选模拟失败后会进入失败并允许重试。复制摘要实际写剪贴板，失败不会宣称成功。按钮为所有状态预留同一宽度。

通过浏览器 Web Animations API 实现，复用现有语义色，无新增运行依赖。系统减少动态效果和页头动效开关均可关闭运动。页面中保存不连接服务，也不持久化配置；数据更新不代表远端状态。

TabsList 的 animated 默认为 true，支持 false 回退；支持 default/line 与横纵向布局。AnimatedNumber 支持 value、locale、formatOptions，辅助技术读取一份最终值；视觉数字副本 aria-hidden。FeedbackButton onAction 仅在 Promise resolve 后显示成功，失败需 throw/reject，error 保留直到重试；pending 不允许重复操作，成功提示 2.2 秒后复位。

验证：真实 Chrome 中 21 项检查通过，包括快速切换定位、键盘选择、数字更新、异步成功与失败重试、完整剪贴板写入和拒绝反馈、系统与手动关闭动效，以及 320/390/768/1440px 明暗主题无页面溢出。记录见 `docs/validation/motion-trio-browser.json`。31 项既有回归测试与 131 项对比度检查通过；类型检查和生产构建通过（保留既有大 chunk 提示）。

## 更多日常控件

预览下半部分新增：通知开关与三项复选框（全选/半选/禁用）、保留输入内容的折叠区域、配置复制、控制实际记录密度的 Popover、可编辑本地名称的 Dialog。所有新增演示沿用页头动效开关，系统减少动态效果设置也生效。

折叠区采用内层 CSS grid 高度过渡，与 Radix Content 的测量层分开，避免测量过程中禁用过渡造成瞬间跳变。关闭后内容 inert 且 aria-hidden，不能被 Tab 访问；打开后草稿仍在。CopyButton 保留可见的失败文字；不会因动画把失败伪装成成功。

本轮新增控件的 24 项真实浏览器检查通过；原三项动效的 21 项检查也重新通过。详细证据与限制见 [motion-controls validation](validation/motion-controls.md)。

## 渐变与深色玻璃预览

页头新增「渐变」与「毛玻璃」开关（毛玻璃仅深色可用）。浅色使用奶油／暖灰渐变；深色用摩卡／灰绿静态层次，主要面板和弹层使用半透明毛玻璃。玻璃模式下嵌套指标卡与代码背景也透明，输入维持实色。可以独立关闭两种效果，直接比较；系统减少透明度偏好优先于玻璃开关。
